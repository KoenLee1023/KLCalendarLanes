# KLCalendarLanes

> [English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)

Deterministic lane allocation for multi-day all-day event bars in a calendar grid. The package is UI-agnostic, supports iOS 17+ and macOS 14+, and has no runtime dependencies.
